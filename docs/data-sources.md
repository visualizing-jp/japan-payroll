# データソース

「事業所は人をどう雇い、いくら払い、何時間働かせてきたか」のための、データソース調査とデータ層の設計。
実装前の実測。調査日: 2026-10-15。

## 1. 結論

全国調査の e-Stat データベース API は 2016-03-31 で止まっている。第1版は REST `getStatsData` を使わない。

正本は e-Stat ファイル「毎月勤労統計調査 全国調査 / 長期時系列表 / 実数・指数累積データ」（tclass `000001144508`）。CSV。最新公開は 2026-09-28、調査月は 2026年7月。

| キー | 統計表ID | ファイル | 用途 |
| --- | --- | --- | --- |
| `jissu` | `000032189776` | `hon-maikin-k-jissu.csv` | 名目実数（円・時間・日・人） |
| `sisu` | `000032189777` | `hon-maikin-k-sisu.csv` | 指数・伸び率。実質賃金、常用雇用指数、パート比率、入離職率 |

`fileKind=1`（CSV）。Excel (`fileKind=4`) は無い。賞与専用表は、実数CSVの「特別給与」列で足りるので第1版では取らない。

出典表記: 厚生労働省「毎月勤労統計調査」全国調査（e-Stat）。

## 2. 採用する切り口（実測）

対象の既定は **調査産業計 `TL` × 事業所規模5人以上 `T`**。

| 列 | 採用コード | 意味 |
| --- | --- | --- |
| 産業分類 | `TL` | 調査産業計。16大産業の合計 |
| 規模 | `T` | 5人以上。`0` は30人以上で1970年〜だが、第1版の既定にはしない |
| 就業形態 | `0` 計 / `1` 一般 / `2` パート | 一般・パートは年次 1993年〜 |
| 月 | `CY` または `01`–`12` | 年次を主系列。月次は同じビューの切替 |

規模の他コード（配信しない）: `4` 500人以上 / `5` 100–499人 / `7` 30–99人 / `9` 5–29人。

### 実数CSV（`jissu`）

ヘッダ（cp932）:

`種別,年,月,産業分類,規模,就業形態,現金給与総額,きまって支給する給与,所定内給与,所定外給与,特別給与,総実労働時間,所定内労働時間,所定外労働時間,出勤日数,前月末労働者数,増加労働者数,減少労働者数,本月末労働者数,パートタイム労働者数`

- `TL` × `T` × 計 × `CY`: **1990–2025**（36年）
- 同条件の月次: **1990年1月–2026年7月**
- 一般・パートの年次: **1993–2025**
- 現金給与総額の単位は円。2025年 CY `TL` `T` 計 = **355,941円**
- 総実労働時間 2025年 CY = **135.1時間**
- 本月末労働者数 2025年 CY = **51,566,253人**
- 2026年の年次行は無い（7月までの月次のみ）

5人以上の年次は1990年開始。1960年代の行は産業別・規模30人以上側に残る。

### 指数CSV（`sisu`）

ヘッダに実質賃金指数（現金給与総額 / きまって支給する給与）、常用雇用、パートタイム労働者比率、入職率、離職率が乗る。指数の基準年は **2020年=100**。

2025年 CY `TL` `T` 計:

- 現金給与総額指数 111.7
- 実質賃金指数（現金給与総額） **98.0**
- 常用雇用指数 105.9
- パートタイム労働者比率 **31.31%**
- 入職率 1.99 / 離職率 1.89（各月の月あたり百分率の年平均。年計ではない）

実質賃金のCPIは、本系列の定義どおり持家の帰属家賃を除く総合。速報の「総合」とは混ぜない。

指数CSVには `指数` と `伸び率、日数差、ポイント差` が並ぶ。配信は **指数行だけ**。伸び率で指数を上書きしない。

- `T / M / T` = 男・形態計。2025年: 26,636,161人、449,528円、150.0時間。2012年: 25,441,570人、401,795円
- `T / F / T` = 女・形態計。2025年: 24,930,093人、255,918円、119.1時間
- 一般 `N` / パート `P` は性の列が空。男/女 × 一般/パートは同じ表に無い

- 実質賃金・入離職・雇用指数は原表に無い
- 2012年シート名は `MKS191 1`、2025年は `実数原表`。データ行の並びに差は無い
- 2012年の数値はカンマ区切り。パーサで除去する
- 月次原表は月ごと（百超）なので、性別の月次は第1版では出さない

cube は `form × sex × metric × time`。`sex` は `0` 計 / `1` 男 / `2` 女。欠ける組合せは `null`（2011年以前の男/女、一般/パート × 男/女、男/女の実質・所定内給与・入離職、月次の男/女）。

## 4. 都道府県（地方調査・年平均）

全国調査の内訳ではない。既存 cube に軸を足さない。別ビュー。

47都道府県サイトは叩かない。厚労省が取りまとめた年平均・表1（事業所規模5人以上、調査産業計）を正本にする。

URL（相対パス `xlsx/{YY}C1T1.xlsx`。`r{YY}/year/xlsx/` は 404）:

`https://www.mhlw.go.jp/toukei/itiran/roudou/monthly/r{YY}/xlsx/{YY}C1T1.xlsx`

| 年 | 和暦 | HTTP | シート |

| 平成30以前 | `h30` など | 404 | 長期の取りまとめファイルはサイトに無い |

実測（2025年 `07C1T1`、2019年 `01C1T1`。列は同じ）:

- 列: 地域 / 常用労働者数（千人） / 総実・所定内・所定外時間 / 出勤日数 / 現金給与総額 / きまって支給する給与 / 所定内給与 / 特別給与
- 性別列は無い
- 全国行があるが、注記どおり全国調査の値。地方調査の合計でも平均でもない

- 2025年東京: 現金給与 459,078円
- 県名は全角スペース入り（`青　森`、`東　京`）。空白を除いて照合する

配信は年次 2019–2025、指標は現金給与総額・総実労働時間・常用雇用。常用は千人 ×1000 を人に戻す。無い年は欠測。

## 5. 見送り

| 候補 | 理由 |
| --- | --- |
| 性別の月次 | 原表が月ごと。年次が載ってから |
| 男/女 × 一般/パート | 原表に交差が無い |
| 年齢 | 特別調査（常用1〜4人の事業所、個人票、年1回）だけ。5人以上の毎月とは混ぜない。UI に準備中タブは出さない |
| 47都道府県サイトの個別取得 | 厚労省の取りまとめ表1で足りる |
| 地方調査と全国調査を同じグラフに重ねる | 調査が違う |
| 規模30人以上を既定にする | 1990年〜の5人以上を既定 |
| 産業の重ね | 第1版の全国配信は `TL` のみ |
| e-Stat REST / 統計ダッシュボード API | 全国調査DBは2016止まり。性別も REST では取らない |

## 6. 配信ファイル

`scripts/build.ts` → `public/data/`

| ファイル | 内容 |
| --- | --- |
| `wages.json` | 年次・月次 cube。指標: cash / contractual / scheduled / overtime_pay / special / real_cash / real_contractual |
| `hours.json` | 総実 / 所定内 / 所定外 / 出勤日数 |
| `employment.json` | 常用雇用人数・パート人数・パート比率・入職率・離職率・常用雇用指数 |
| `prefecture.json` | 地方調査の年次 cube。指標: cash / hours / workers |
| `meta.json` | 最新年次、最新月、CPI定義、出典 |

全国の cube は `form × sex × metric × time`。地方は `pref × metric × time`。値の欠測は `null`。

- 円・時間・日・人は実数のまま
- パート比率・入職率・離職率は百分率を ÷100 して小数にする
- 入職率・離職率の月次は月あたり。4月は定期採用で高い（2024年4月入職 5.33、他月はおおむね 1.4–2.3）。年次はその12か月平均（2024年 2.04）。年次値を月次系列へ混ぜてはいない
- 指数はそのまま

## 7. 注記（UIに短く出す）

- 常用労働者は期間の定めなし、または1か月以上。労働力調査の就業者ではない。
- 5人以上の年次は1990年〜。一般・パートは1993年〜。性別の年次は2012年〜。
- 男/女は就業形態計だけ。実質賃金と所定内給与は性別で出ていない。
- 地方調査の値は全国調査の内訳ではない。全国行は全国調査。
- 標本ローテーション、ベンチマーク更新、2018年問題以降の接続に注意。
- 実質賃金指数の基準は2020年=100。
